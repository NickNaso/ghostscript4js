# @ghostscript4js/darwin-arm64

The prebuilt [ghostscript4js](https://github.com/NickNaso/ghostscript4js) addon for macOS arm64. It contains the addon, with Ghostscript from [libgs](https://github.com/NickNaso/libgs) linked statically.

Do not install this package directly: npm installs it as an optional dependency of `ghostscript4js` on the matching
platform, and `ghostscript4js` loads it.
