# @ghostscript4js/linux-arm64-musl

The prebuilt [ghostscript4js](https://github.com/NickNaso/ghostscript4js) addon for Linux arm64 with musl. It contains the addon, with Ghostscript from [libgs](https://github.com/NickNaso/libgs) linked statically.

Do not install this package directly: npm installs it as an optional dependency of `ghostscript4js` on the matching
platform, and `ghostscript4js` loads it.
