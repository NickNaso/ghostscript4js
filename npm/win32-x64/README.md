# @ghostscript4js/win32-x64

The prebuilt [ghostscript4js](https://github.com/NickNaso/ghostscript4js) addon for Windows x64. It contains the addon and `gsdll64.dll`, the Ghostscript DLL of [libgs](https://github.com/NickNaso/libgs) that the addon loads from its own folder.

Do not install this package directly: npm installs it as an optional dependency of `ghostscript4js` on the matching
platform, and `ghostscript4js` loads it.
